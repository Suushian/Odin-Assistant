# دریافت و اعتبارسنجی دادهٔ تاریخی بک‌تست

این ابزارها از مسیر دادهٔ زندهٔ برنامه جدا هستند و `config.yaml` را تغییر نمی‌دهند.

## بازهٔ پیش‌فرض

از `2026-04-13` تا `2026-10-13` (تاریخ پایان در CLI ابزار Dukascopy طبق تعریف خود ابزار تفسیر می‌شود؛ پوشش واقعی باید در CSV بررسی شود).

نمادها: EURUSD، GBPUSD، USDJPY، USDCAD، AUDUSD، USDCHF و XAUUSD نقدی. تایم‌فریم‌ها: M15، H1 و H4.

## پیش‌نیاز

- Python 3.10+
- Node.js/npm نصب‌شده و دسترسی شبکه
- دسترسی به ابزار/نمادهای موردنیاز در Dukascopy

## دریافت داده

ابتدا فرمان‌ها را بدون دانلود بررسی کنید:

```bash
python scripts/backtest/download_data.py --dry-run
```

سپس دانلود را اجرا کنید:

```bash
python scripts/backtest/download_data.py
```

برای نماد یا تایم‌فریم محدود:

```bash
python scripts/backtest/download_data.py --symbols EURUSD XAUUSD --timeframes m15 h1
```

داده‌ها زیر `data/historical/dukascopy/<SYMBOL>/<TIMEFRAME>/` ذخیره می‌شوند. ابزار `dukascopy-node` با `npx --yes` اجرا می‌شود؛ اولین اجرا ممکن است بسته را دریافت کند. اگر ابزار یا نمادی در دسترس نبود، خطا ثبت می‌شود؛ خطای دانلود را موفقیت تلقی نکنید.

## اعتبارسنجی

```bash
python scripts/backtest/validate_data.py
```

گزارش JSON در `data/historical/validation-report.json` نوشته می‌شود و شامل تعداد ردیف‌ها، ابتدا/انتهای UTC، ستون‌ها، زمان‌های تکراری، ترتیب زمانی، OHLC نامعتبر و فاصله‌های بزرگ بین کندل‌هاست.

### محدودیت‌های گزارش

- وجود CSV به‌تنهایی اثبات پوشش کامل شش‌ماهه نیست؛ ابتدا و انتهای بازه و تعداد کندل‌ها باید با بازهٔ درخواستی تطبیق داده شود.
- فاصله‌های بزرگ می‌توانند به دلیل آخر هفته یا تعطیلی عادی بازار باشند. شمارندهٔ فاصله‌ها فقط برای تشخیص اولیه است و به‌تنهایی خطای داده را اثبات نمی‌کند.
- این اعتبارسنجی ساختار CSV و OHLC را می‌سنجد؛ کیفیت قیمت، تفاوت ساعت تابستانی منبع، اسپرد، کمیسیون، سوآپ و دقت داده در سطح بروکر را تأیید نمی‌کند.
- این ابزار دادهٔ تاریخی تقویم اقتصادی، خبرها یا تأییدیه‌های TradingView را بازسازی نمی‌کند. نتایج بک‌تست بدون آرشیوهای زمان‌مند آن‌ها باید با این محدودیت گزارش شوند.
- فایل‌های تاریخی دانلودشده را commit نکنید؛ گزارش نهایی باید منبع، بازهٔ واقعی، تعداد ردیف‌ها و هر شکاف را ثبت کند.

## وضعیت

این مرحله ابزار دریافت و ممیزی داده را آماده می‌کند. اجرای واقعی دانلود و اعتبارسنجی باید در محیطی با Node.js و دسترسی شبکه انجام شود؛ تا آن زمان پوشش تاریخی شش‌ماهه تأییدشده محسوب نمی‌شود.
