# پیشنهادهای لوگو (بایگانیِ فرایند)

این پوشه مسیرِ انتخابِ نشان تازه (نسخهٔ ۱.۳.۰) را نگه می‌دارد. نشانِ نهایی
**«پالسِ منفی»** است و هندسهٔ آن در `assets/brand_mark.py` زندگی می‌کند؛
بقیهٔ فایل‌ها فقط تاریخچهٔ تصمیم‌اند و در کد استفاده نمی‌شوند.

| فایل | چیست |
|---|---|
| `pulse-variants.png` | پوسترِ ۸ نسخهٔ ایدهٔ پالس (مبنای انتخاب) |
| `pulse-01.png` … `pulse-08.png` | همان ۸ نسخه در ۵۱۲ پیکسل — **`pulse-02.png` انتخاب شد** |
| `applied-preview.png` | نشانِ نهایی روی سطوح واقعی (آیکون، اسپلش، اعلان، هدر) |
| `ideas-overview.png` | دستهٔ اول پیشنهادها (۱۰ ایدهٔ فرم‌محور) — کنار گذاشته شد |
| `idea-01.png` … `idea-10.png` | نسخه‌های ۵۱۲ همان دسته |
| `preview.html` | پیش‌نمایش HTMLِ دستهٔ اول (فقط بایگانی) |

قاعدهٔ کار: هر تغییری در نشان باید از `assets/brand_mark.py` شروع شود و با
`python assets/make_icon.py` و `node tests/js/smoke_brand_identity.js` تأیید شود.
