# 📦 یادداشت انتشار — نسخهٔ ۱٫۰٫۱

**تاریخ:** ۲۴ نوامبر ۲۰۲۶ · **پیشیاز:** ۱٫۰٫۰ (۲۲ اکتبر ۲۰۲۶) · **نوع:** انتشار عمومی اندروید (debug-signed)

> این نسخه، حاصل پنج مرحله کار روی «کیفیت سیگنال» و «درستی اندازه‌گیری» است.
> هیچ‌کدام از قفل‌های تازه به‌طور پیش‌فرض روشن نیستند: رفتار موتور دقیقاً مثل
> ۱٫۰٫۰ است، ولی حالا می‌توانی **با دادهٔ خودت** ببینی کدام تنظیم بهتر است.

---

## ۱) یک جمله‌ای
سیستم از «سیگنال بیشتر» به «سیگنال قابل‌سنجش» تغییر کرد: هر تغییری که بدهی،
با یک فرمان می‌توانی ببینی سود داد یا نه.

## ۲) چه چیزی تازه است

### خواندن درست داده (مهم‌ترین اصلاح)
فایل CSV متاتریدر قیمت را در «point» می‌دهد (`112066` به‌جای `1.12066`).
قبلاً این حالت بی‌سروصدا هزینه‌ها را صفر می‌کرد و بک‌تست را **۱۵۷R خوش‌بینانه**
نشان می‌داد. حالا برنامه خودش تشخیص می‌دهد، اصلاح می‌کند و هشدار می‌دهد.

### دروازهٔ استراتژی و دروازهٔ نماد
در تنظیمات می‌توانی یک ستاپ یا یک نماد را خاموش کنی، یا آستانهٔ امتیاز
اختصاصی برایش بگذاری:

```yaml
judge:
  strategy_gate: { enabled: true, breakout: { enabled: false } }
  symbol_gate:   { enabled: true, GBPUSD:  { min_score: 7 } }
```
دلیل رد همیشه صریح است: «⛔ ستاپ خاموش شده» یا «⛔ نماد خاموش شده»؛ نه سکوت.

### سه برش تشخیصی در بک‌تست
جدول‌های **به تفکیک امتیاز**، **ساعت ورود (UTC)** و **روز هفته** به گزارش
اضافه شد. دیگر لازم نیست حدس بزنی کدام بازهٔ امتیاز یا کدام ساعت پول می‌سوزاند.

### جاروی آستانهٔ امتیاز
```bash
python tools/backtest.py --data-dir ~/odin-m15 --sweep-min-score 5,6,7,8
```
چند آستانه روی همان داده، یک جدول مقایسه، و یک پیشنهاد صریح — فقط از میان
گزینه‌هایی با **≥۱۰۰ معامله** تا یک برندهٔ خوش‌شانس با ۱۲ معامله گزارش نشود.

### آزمون برون‌نمونه و کالیبراسیون خودکار
```bash
python tools/backtest.py --data-dir ~/odin-m15 --split --min-score auto
```
`--split` بازه را نصف می‌کند و می‌گوید نتیجه در نیمهٔ دوم هم تکرار می‌شود یا نه
(تجربه نشان داد رتبهٔ استراتژی‌ها بین دو بازه برعکس می‌شود).
`--min-score auto` آستانه را از خودِ داده انتخاب می‌کند.

### سه حالت خروج (برای اندازه‌گیری، پیش‌فرض خاموش)
`--exit-mode fixed|be|trail` — سربه‌سر در +۱R یا دنباله‌رو ۱R.
اندازه‌گیری ما: سربه‌سر **افت را کم می‌کند ولی سود را هم می‌خورد**؛ تصمیم با
دادهٔ خودت.

### ابزار یک‌فرمانی
```bat
quality-check.bat
```
داده را پیدا می‌کند، بک‌تست پایه + جارو را می‌گیرد، و خلاصهٔ فارسی را چاپ
می‌کند: کدام استراتژی/نماد/امتیاز سودده است و کدام نه.

## ۳) ظاهر و رابط کاربری
هویت بصری «Aurora Glass 2.1» از ۱٫۵٫۰: کارت‌های عمیق‌تر، اعداد بزرگ‌تر،
تب فعال به‌صورت قرص افقی، و شیشهٔ لطیف فقط در لایه‌های رویی (نه همه‌جا).

## ۴) صداقت اندازه‌گیری — نتیجهٔ بک‌تست واقعی
روی ۹ نماد M15 واقعی، ۲۰۱۹ تا ۲۰۲۱ (۱٬۶۸۸ معامله):

| معیار | مقدار |
|---|---|
| نرخ برد | ۳۳٫۷٪ (سربه‌سر با RR=۲: ۳۳٫۳۳٪) |
| میانگین R | −۰٫۰۰۰ · PF ۱٫۰۰ |
| حداکثر افت | −۳۰٫۴R |

یعنی موتور دقیقاً روی خط هزینه ایستاده است. **این نسخه سود تضمین نمی‌کند**؛
ابزارهایی می‌دهد که با آن‌ها می‌توانی خودت تصمیم بگیری چه چیزی را روشن بگذاری.

## ۵) نصب

1. فایل `ODIN-Assistant-v1.0.1-debug.apk` را از همین صفحهٔ Release بگیر.
2. اگر نسخهٔ **دیباگ ۱٫۴ تا ۱٫۶** را نصب کرده بودی، اول آن را حذف کن
   (شمارهٔ نسخهٔ داخلی آن‌ها بالاتر بود و اندروید اجازهٔ نصب نسخهٔ پایین‌تر را نمی‌دهد).
3. نصب از منابع ناشناس را برای فایل‌منیجر اجازه بده.
4. کلید Twelve Data را در «تنظیمات» وارد کن.
5. برای رصد پس‌زمینه، اعلان‌ها و محدودیت باتری را بررسی کن.

**امضا:** debug keystore (نسخهٔ تست). برای انتشار در استور، keystore رسمی لازم است.
