## معرفی

ODIN بازار فارکس و طلا را از چهار منظر بررسی می‌کند: تحلیل تکنیکال، داده‌های فاندامنتال، اخبار و تأییدیهٔ TradingView. نتیجه، همراه با دلایل فارسی، روی گوشی نمایش داده می‌شود؛ حتی هنگام فعال بودن رصد پس‌زمینه.

- **فقط تحلیل و پیشنهاد:** به بروکر متصل نمی‌شود و معامله‌ای اجرا نمی‌کند.
- **شفافیت:** دلیل صدور یا رد هر سیگنال ثبت و نمایش داده می‌شود.
- **دادهٔ رایگان:** بدون کلید API، سرور اختصاصی یا متاتریدر.
- **حریم خصوصی:** داده‌ای از گوشی به سرور اختصاصی پروژه ارسال نمی‌شود.

## قابلیت‌ها

| بخش | امکانات |
|---|---|
| تحلیل و سیگنال | تحلیل H4/H1، داور امتیازدهی، دروازه‌های وتو و توافق استراتژی‌ها |
| رصد پس‌زمینه | تحلیل دوره‌ای، اعلان سیگنال، خبر فوری و هشدار قیمت |
| ژورنال | ثبت append-only، ارزیابی خودکار نتیجه و گزارش هفتگی نرخ برد و میانگین R |
| نمودار | کندل‌های H1/H4، سطوح حمایت و مقاومت و نمایش سیگنال |
| هشدار قیمت | عبور از سطح، حالت یک‌بارمصرف یا چسبنده و cooldown |
| اشتراک‌گذاری | کارت تصویری سیگنال با تاریخ جلالی و ساعت تهران |
| تجربهٔ فارسی | ارقام فارسی، تاریخ جلالی و ترجمهٔ رویدادهای تقویم اقتصادی |
| ظاهر | Aurora Glass 2.0، کارت‌های تیره، آیکون‌های SVG و رنگ‌بندی معنایی |
| مجوز | تریال ۷ روزه، لایسنس متصل به کد دستگاه و کنترل دستکاری ساعت |

### منابع داده

- قیمت‌ها و کندل‌ها: [Yahoo Finance](https://finance.yahoo.com/)
- تقویم اقتصادی: [ForexFactory](https://www.forexfactory.com/)
- اخبار: فیدهای RSS منابع فارکس
- تأییدیهٔ تکنیکال: API غیررسمی TradingView

این منابع به کلید API نیاز ندارند. در صورت نبود داده، ODIN باید وضعیت ناموجود را صادقانه گزارش کند؛ نه اینکه دادهٔ جعلی یا کهنه را جایگزین کند.

## منطق صدور سیگنال

هر چرخهٔ تحلیل از چند مرحله می‌گذرد:

```text
داده و اعتبارسنجی → تحلیل → دروازه‌های وتو → امتیازدهی → توافق استراتژی‌ها → سیگنال
```

### استراتژی‌های ورود

| استراتژی | خلاصهٔ منطق | نقش |
|---|---|---|
| روند + پولبک | روند H4 و H1، ADX و پولبک RSI همراه با تأیید ادامهٔ حرکت | پیشنهاددهنده |
| شکست لندن | شکست محدودهٔ آسیا در بازهٔ زمانی مشخص، با فیلتر ATR | پیشنهاددهنده |
| کری (نرخ بهره) | اختلاف نرخ سیاستی همراه با رتبهٔ قدرت ارزها و اخبار | فقط تأیید؛ به‌تنهایی سیگنال نمی‌سازد |

استراتژی‌ها از تنظیمات قابل فعال یا غیرفعال شدن‌اند. برای صدور سیگنال، دست‌کم یک استراتژیِ پیشنهاددهنده باید هم‌جهت باشد و حداقل توافق تنظیم‌شده برقرار بماند. خاموش بودن همهٔ استراتژی‌های پیشنهاددهنده به معنی صادر نشدن سیگنال است.

### داور امتیازدهی

- **۷ دروازهٔ وتو:** دادهٔ ناکافی، بازار بسته، تضاد تایم‌فریم، بازار بی‌روند، رویداد پراثر، جهش غیرعادی نوسان و خبر فوری.
- **حداکثر ۱۱ امتیاز:** روند (۲)، سطح کلیدی (۲)، فاندامنتال (۲)، RSI (۱)، قدرت ارزها (۱)، اخبار (۱)، TradingView (۱) و سشن نقدشونده (۱).
- **آستانهٔ پیش‌فرض صدور: ۷ از ۱۱**؛ وتوها مستقل از امتیاز عمل می‌کنند.
- **دادهٔ ناموجود امتیاز صفر می‌گیرد** و با نشانهٔ عدم دسترسی نمایش داده می‌شود.
- دلیل رد شدن نیز مشخص است: وتو، نبود ستاپ، امتیاز ناکافی، نبود توافق استراتژی یا رسیدن به سقف سیگنال چرخه.

## ژورنال و کارنامه

- هر سیگنال در ژورنال append-only ثبت می‌شود.
- نتیجه با کندل‌های M15 و بر اساس هدف، حد ضرر یا انقضای ۴۸ ساعته ارزیابی می‌شود.
- اگر یک کندل هم هدف و هم حد ضرر را لمس کند، نتیجه با رویکرد محتاطانه «ضرر» محاسبه می‌شود.
- گزارش هفتگی شامل نرخ برد، میانگین R، مقایسه با هفتهٔ قبل و تفکیک نتایج بر اساس نماد، جهت، امتیاز، استراتژی و مدرک است.
- اعلان سیگنال تکراری با cooldown یا تا زمان بهبود محسوس امتیاز محدود می‌شود.

**کارنامه گذشته را توصیف می‌کند؛ تضمینی برای عملکرد آینده نیست.**

## رصد پس‌زمینه

- فاصلهٔ تحلیل قابل تنظیم است؛ مقدار پیش‌فرض ۱۵ دقیقه و محدودهٔ تنظیم ۵ تا ۲۴۰ دقیقه است.
- هنگام بسته بودن بازار، بررسی‌ها با فاصلهٔ ۳۰ دقیقه انجام می‌شوند.
- اعلان سیگنال جدید، خبر فوری غیرتکراری و هشدار قیمت پشتیبانی می‌شوند.
- اعلان ماندگار، خلاصهٔ وضعیت رصد را نمایش می‌دهد.
- برای عملکرد قابل اتکاتر، مجوز اعلان و استثنا از بهینه‌سازی باتری (Doze/OEM) ممکن است لازم باشد.

## نصب و فعال‌سازی

1. آخرین فایل APK را از [صفحهٔ Releases](https://github.com/Suushian/Odin-Assistant/releases/latest) دریافت کنید.
2. روی Android 7.0 یا جدیدتر نصب کنید؛ ممکن است لازم باشد اجازهٔ نصب از منابع ناشناس را فعال کنید.
3. از تریال ۷ روزه استفاده کنید یا برای دریافت لایسنس با [کانال رسمی](https://t.me/Khode_Sushian) تماس بگیرید.
4. برای رصد پس‌زمینه، این قابلیت را در برنامه فعال و مجوزهای مربوط را بررسی کنید.

لایسنس به کد دستگاه متصل است و برای استفاده روی دستگاه دیگر قابل کپی نیست. قالب‌های پشتیبانی‌شده شامل کلید دائمی ۱۹ نویسه‌ای و کلید زمان‌دار ۲۶ نویسه‌ای هستند.

## معماری

ODIN دو موتور هم‌رفتار دارد؛ **JavaScript موتور فعال برنامهٔ اندروید** است و **Python به‌عنوان اوراکل parity و نسخهٔ دسکتاپ منجمدشده** نگهداری می‌شود.

- **Contract-based و plugin-driven:** قابلیت‌ها از طریق قرارداد و مانیفست پلاگین‌ها ثبت می‌شوند.
- **Pipeline نام‌دار:** چرخهٔ تحلیل مرحله‌بندی شده و قابلیت توقف کنترل‌شده دارد.
- **Failure isolation:** خرابی پلاگین به وضعیت unavailable و گزارش خطا تبدیل می‌شود؛ نباید دادهٔ جعلی تولید کند.
- **هم‌ارزی دو موتور:** تست‌های طلایی و parity خروجی JavaScript را با اوراکل Python مقایسه می‌کنند.
- **اندروید سبک:** کد رابط در WebView و JavaScript خالص ES5 اجرا می‌شود؛ وابستگی بیرونی اندرویدی اضافه نشده است.

```text
Android / JavaScript  →  داده → تحلیل → ژورنال → داور → سیگنال و اعلان
          ↕ تست‌های parity
Python / Oracle       →  مرجع مقایسهٔ رفتار و تست‌های طلایی
```

نسخهٔ دسکتاپ ویندوز از v0.21.0 منجمد شده است؛ توسعهٔ محصول روی اندروید ادامه دارد. خروجی قابل توزیع فعلی APK است.

## کیفیت و راستی‌آزمایی

پروژه تست‌های واحد، تست‌های طلایی، تست‌های smoke رابط، بررسی پیکربندی و تست‌های parity دارد. مستندات پروژه بیش از ۲٬۰۰۰ بررسی خودکار، ۷۸ سناریوی طلایی برای استراتژی‌ها و ۲۷ بررسی parity زنده را ثبت کرده‌اند؛ این اعداد توصیف مجموعهٔ تست مستندشده‌اند، نه تضمین کیفیت داده یا سودآوری.

اجرای تست‌های آفلاین در محیط توسعه:

```bash
python main.py --selftest
python tests/check_config.py
for t in tests/test_*.py; do python "$t"; done
for s in tests/js/smoke_*.js tests/js/test_*.js; do node "$s"; done
```

تست‌های parity زنده و سرویس پس‌زمینه به اینترنت نیاز دارند و در همهٔ اجراهای CI اجرا نمی‌شوند. پایداری روی دستگاه واقعی نیز باید جداگانه بررسی شود.

## محدودیت‌های شناخته‌شده

- استراتژی‌ها عمداً تعداد سیگنال‌ها را محدود می‌کنند؛ کیفیت یا نرخ برد تضمین نمی‌شود.
- جدول نرخ‌های سیاستی کری دستی است و باید از منابع عمومی به‌روزرسانی شود؛ برای طلا سیگنال کری صادر نمی‌شود.
- API غیررسمی TradingView ممکن است در دسترس نباشد؛ در این حالت مدرک ناموجود، امتیاز صفر می‌گیرد.
- Yahoo Finance ممکن است کند یا قطع باشد؛ دادهٔ ناکافی باید باعث رد تحلیل شود.
- هنوز اسکرین‌شات واقعی اندروید از دستگاه یا شبیه‌ساز ثبت نشده است.
- لایسنس آفلاین محدودیت‌های ذاتی خود را دارد؛ جزئیات در [راهنمای لایسنس](LICENSE_GUIDE.md) آمده است.

## نقشهٔ راه

**تکمیل‌شده:** تحلیل و داده، فاندامنتال و اخبار، داور، ژورنال، اندروید و رصد پس‌زمینه، لایسنس و تریال، هشدار و نمودار، کارت تصویری، Aurora Glass 2.0، معماری پلاگین، استراتژی‌ها و دروازهٔ توافق، تنظیمات استراتژی‌ها، کارنامهٔ تفکیکی و وضعیت پلاگین‌ها.

**در انتظار:** اعتبارسنجی رصد پس‌زمینه روی گوشی‌های واقعی و نسخه‌های مختلف Android/OEM، ثبت اسکرین‌شات واقعی اندروید و دورهٔ shadow برای ارزیابی دقت با دادهٔ ژورنال.

## توسعه‌دهندگان

پیش از تغییر کد، [بستهٔ زمینهٔ توسعه](docs/ODIN-AI-Context-Pack-fa.md) را بخوانید. این سند ساختار ریپو، قوانین سازگاری، تست‌ها و محدودیت‌های شناخته‌شده را شرح می‌دهد.

- [معماری پلاگین‌ها](docs/plugin-architecture-fa.md)
- [راهنمای اندروید](docs/android-fa.md)
- [تاریخچهٔ نسخه‌ها](CHANGELOG.md)
- برنچ فعال: main؛ تغییرات باید از طریق Pull Request وارد شوند.
- قابلیت جدید معمولاً به adapter و مانیفست در src/plugins/ و js/plugins.js به‌همراه تست طلایی نیاز دارد.
- کدهای android/app/src/main/assets/www/js/ باید با ES5 سازگار بمانند.
- پیش از refactor، رفتار فعلی را با تست تثبیت کنید؛ تست طلایی را بدون دلیل موجه تغییر ندهید.
